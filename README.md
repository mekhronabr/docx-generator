# Генератор Огоҳинома

Приложение читает Excel и по одному нажатию создаёт **общие Word-документы для печати**. В каждом файле — до 1000 студентов (число настраивается от 1 до 1000). Каждое уведомление начинается с новой страницы. Для 4000 студентов при размере части 1000 появляются четыре кнопки скачивания DOCX. ZIP и тысячи отдельных файлов скачивать не требуется.

Откройте скачанную часть в Microsoft Word, нажмите **Ctrl+P** (на Mac **⌘P**), выберите принтер и печать всего документа. Это один запуск печати на часть. Сайт не отправляет задания на ваш принтер автоматически. Не печатайте страницу браузера: печатать нужно скачанный Word-файл.

## Файлы проекта

- `app.py` — полный код приложения, обработки данных и потоковой сборки документов.
- `requirements.txt` — зависимости.
- `example.xlsx` — пустая таблица с таджикскими заголовками для скачивания на странице.
- `template.docx` — готовый шаблон на основе присланного «ОГОҲИНОМА.docx».
- `.streamlit/config.toml` — ограничение загрузки Excel до 20 МБ.
- `.gitignore` — исключения для Git.

«ОГОҲИНОМА (пурра).docx» использован для сравнения. Его дополнительная страница обязанностей не добавлена в короткий шаблон: основной исходник указан в запросе. Текст документов рассматривается как содержимое, а не инструкции для приложения.

## Подготовка Excel

Первая строка первого листа — заголовки. Одна следующая строка — один студент. Никаких объединённых ячеек, дополнительных заголовков и итогов среди данных.

Названия колонок (регистр не важен, точки и слова должны совпадать):

1. `ФИО Студента`
2. `Курс`
3. `Группа`
4. `Специальность`
5. `Факультет`
6. `ФИО Куратора`
7. `Телефон Куратора`
8. `ФИО Зам. декана`
9. `Телефон Зам. декана`
10. `ФИО Декана`
11. `Телефон Декана`

Три телефонные колонки должны существовать, но их ячейки можно оставлять пустыми. Остальные поля обязательны. Полностью пустые строки пропускаются. ФИО и факультет сотрудников заполняйте для каждого студента: автоматического переноса данных из предыдущей строки нет.

Для телефонов, группы и кода специальности **до ввода данных** задайте формат ячеек «Текстовый». Например, телефон `+992 92-123-45-67`, группа `1.53.01.05тб`, код специальности `1.53.01.05`. Если Excel уже удалил начальные нули, приложение не сможет их восстановить. Используйте обычные значения, а не формулы: если формулы необходимы, предварительно пересчитайте и сохраните книгу в Excel.

Присланная таблица с таджикскими заголовками также поддерживается без переименования. Отдельная колонка кода специальности не нужна: приложение берёт код из группы, убирая буквы в конце. Например, `1.53.01.05тб` превращается в `1.53.01.05 – название специальности`, а `344` или `344аб` — в `344 – название специальности`. В поле группы остаётся исходное значение. Если в старом файле есть отдельная колонка `Код специальности`, она игнорируется.

Пример первой строки данных:

```text
ФИО Студента: Иванов Иван Иванович
Курс: 1
Группа: 1.53.01.05тб
Специальность: Ҳаракатдиҳандаҳои автоматии барқӣ
Факультет: Факултети энергетика
ФИО Куратора: Петров Пётр Петрович
Телефон Куратора: +992 92-123-45-67
ФИО Зам. декана: Сидорова Анна
Телефон Зам. декана: [оставьте ячейку пустой]
ФИО Декана: Смирнов Алексей Иванович
Телефон Декана: [оставьте ячейку пустой]
```

В документ попадёт `Петров Пётр Петрович (+992 92-123-45-67)` и `Сидорова Анна`, без пустых скобок. Подписи: `Иванов И.И.`, `Смирнов А.И.`. Алгоритм считает первое слово фамилией, остальные — именем и отчеством. Для `Акрамзода Фирдавсҷон` результат — `Акрамзода Ф.`. Полное ФИО студента сверху выводится ПРОПИСНЫМИ буквами, как в образце. В остальных ФИО каждое слово и часть двойной фамилии начинаются с заглавной буквы, инициалы — заглавные. Для факультета и специальности используется заглавная первая буква и строчные остальные; распространённые сокращения ИТ, IT, ICT, ЭВМ, CAD, CAM, ЧПУ сохраняются. Если в названиях встречаются другие аббревиатуры, добавьте их в набор `acronyms` функции `normalize_label`. Буквы в группе приводятся к строчным. Лишние пробелы и переносы строк удаляются. Жирность, курсив и подчёркивание вставок задаются шаблоном и не зависят от оформления Excel.

## Шаблон Word

В присланном файле теги уже были вставлены. Подготовленный `template.docx` сохраняет оформление, таблицы, размер страницы и встроенные шрифты исходника; пробелы у тега специальности нормализованы. Никакого поиска `~` при генерации нет.

Используемые теги:

```jinja2
{{ faculty }}
{{ student_name }}
{{ course }}
{{ group }}
{{ group_numbers }}
{{ spec }}
{{ curator_info }}
{{ zam_dekan_info }}
{{ dekan_info }}
{{ dekan_short }}
{{ student_short }}
```

Также программно доступен `{{ curator_short }}`, если понадобится добавить подпись куратора. Не заполняйте инициалы в Excel.

Если редактируете шаблон, пишите тег целиком в одном фрагменте с одинаковым форматированием. Не добавляйте разделы, колонтитулы, рисунки, закладки, ссылки и сноски: сборщик рассчитан на повторение комплектного статического шаблона. Текстовые правки и обычные таблицы допустимы. Не включайте переменные в общие части пакета Word. Файл должен остаться `template.docx` рядом с `app.py`.

**Печать:** исходный шаблон имеет размер Letter, а не A4. Сохранён именно исходный размер. При печати на A4 выберите масштабирование под бумагу либо заранее измените размер страницы шаблона в Word и проверьте пробную печать. Длинные ФИО и названия могут занять дополнительную страницу; начало следующего студента всё равно будет на новой странице. Для односторонних уведомлений отключите двустороннюю печать. Перед большим тиражом проверьте 2–3 уведомления в предпросмотре Word.

## Локальный запуск — Windows

1. Установите Python 3.12 с https://www.python.org/downloads/. В установщике отметьте **Add python.exe to PATH**.
2. Создайте папку `C:\ogohinoma` и положите в неё файлы проекта. Не переносите чужую папку `venv`.
3. Откройте меню «Пуск», найдите **Командная строка** и запустите её. Инструкции ниже для cmd, не PowerShell.
4. По очереди выполните:

```bat
cd C:\ogohinoma
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

5. Дождитесь открытия браузера. Если он не открылся, перейдите на http://localhost:8501.
6. Загрузите Excel, оставьте 1000 студентов на документ или уменьшите число и нажмите **Сгенерировать документы**.
7. Скачивайте готовые части по мере появления. Нажатие скачивания не перезапускает генерацию.
8. Откройте каждый файл в Word и отправьте его целиком на печать.
9. Чтобы остановить приложение, нажмите **Ctrl+C** в командной строке.
10. Для повторного запуска достаточно двух команд:

```bat
cd C:\ogohinoma
.venv\Scripts\python.exe -m streamlit run app.py
```

## Локальный запуск — macOS

1. Установите Python 3.12 с python.org, если его нет.
2. Откройте приложение **Терминал**.
3. В вашем текущем проекте выполните:

```sh
cd /Users/mehrona/projects/docx-generator
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

4. Откройте http://localhost:8501, загрузите Excel и запустите генерацию.
5. Скачайте части, откройте их в Word и нажмите **⌘P**.
6. Остановка — **Ctrl+C** в Терминале. В следующий раз повторите только `cd ...` и последнюю команду запуска.

Если проект расположен в другой папке, измените путь после `cd`. Если путь содержит пробелы, заключите его в двойные кавычки.

## Память, скорость и восстановление

`ThreadPoolExecutor` использует два потока: у каждого свой экземпляр `DocxTemplate`. В очереди максимум четыре задания. XML каждого уведомления кратковременно хранится во временной папке, последовательно записывается в общий DOCX и удаляется. Промежуточные DOCX со встроенными шрифтами не пересжимаются для каждого студента. Встроенные шрифты и другие общие части пакета копируются один раз на общий документ. Рабочая копия шаблона для Jinja не содержит бинарных файлов шрифтов: при текстовой подстановке они не нужны, а итоговый документ получает их из оригинала. В памяти не строится дерево XML на 1000 страниц.

Общие Word-файлы остаются в памяти сеанса для `st.download_button`; передача файлового объекта сама по себе не устраняет это хранение. Поэтому есть лимит: после достижения 64 МБ готовых частей генерация приостанавливается. Возможен выход за этот порог на размер одной части (не больше 64 МБ); Streamlit и загрузка Excel дополнительно потребляют память. Скачайте части, нажмите **Показать продолжение**, затем **Части скачаны — продолжить**. Предыдущие кнопки будут удалены, генерация продолжится со следующего студента. Обычные 4000 строк обрабатываются автоматически, если суммарный размер частей ниже порога.

Параллельность не гарантирует ускорение на каждом процессоре: работа XML частично ограничена GIL и доступными CPU. Два потока выбраны как умеренный расход памяти; при необходимости меняйте `MAX_WORKERS` в коде после замера на вашем компьютере. Не увеличивайте его без необходимости на бесплатном хостинге.

Лимит загрузки — 20 МБ, распакованного XLSX — 100 МБ, число строк за загрузку — до 100 000. Это защитные ограничения, а не гарантия работы при любых данных и количестве одновременных пользователей. Тяжёлые таблицы с лишним форматированием лучше предварительно сократить.

При ошибке готовые части остаются доступны, незавершённая часть не выдаётся как успешная. Нажмите **Показать восстановление** и продолжите после скачивания готовых частей. Смена файла или размера части сбрасывает результаты; сначала скачайте их. Перезагрузка сервера, закрытие сеанса и потеря соединения могут уничтожить результаты: постоянного хранилища здесь нет. При остановке на первой части используйте **Сгенерировать документы** повторно.

Excel не сохраняется в репозитории и не кэшируется глобально. Каждый сеанс имеет свои результаты; временные папки удаляются при завершении и обычных исключениях. Для работы с настоящими персональными данными настройте доступ к облачному приложению согласно правилам вашей организации или запускайте локально.

## Частые проблемы

- **ModuleNotFoundError:** установите `requirements.txt` тем же Python из `.venv`, которым запускаете приложение.
- **Файл шаблона не найден:** проверьте точное имя `template.docx`, соседство с `app.py` и наличие файла на GitHub.
- **Не хватает колонок:** скопируйте названия из списка выше. Не смешивайте две колонки с русским и таджикским названием одного поля.
- **Пустое обязательное поле:** приложение показывает номера строк Excel. Заполните поля и загрузите исправленную таблицу.
- **Документ занимает больше страниц:** проверьте длину полей, установленные шрифты, размер бумаги и предпросмотр Word. Приложение не сокращает текст автоматически.
- **Облако перезапускается:** уменьшите размер части до 500 или 100, проверьте размер шаблона, закройте лишние сеансы. Для большого тиража локальный запуск обычно предсказуемее.
- **Нужен один документ:** если студентов не больше 1000, поставьте размер части не меньше их количества. Для большего тиража приложение намеренно выдаёт несколько частей.

## Второй шаблон — Талабот саҳифаи 2

В меню «Шаблон документа» выберите «Талабот». Исходный файл
сохранён как `template_talabot.docx`; заполнение выполняет `talabot.py`.
Оба файла должны находиться рядом с `app.py` при локальном запуске и публикации.

Можно менять код факультета (например, `ФЭ_11`), группу (`1_53.01.05тб`), дату,
ФИО куратора и заместителя, список студентов и список отсутствующих.
ФИО вводятся по одному на строку с сохранением регистра. Основной список
вмещает 40 человек (1–20 слева, 21–40 справа), список отсутствующих — 10.
Пустые места и поля для подписей сохраняются.

Скачайте пустой Excel в этом режиме либо загрузите существующий файл и
выберите колонку с ФИО. Если есть колонка «Группа» или «Гурӯҳ», выберите
нужную группу. После загрузки список можно исправить в форме. Нажмите
«Сгенерировать документ» и скачайте заполненный Word.

Для пакетной генерации выберите «Несколько групп». Загрузите один Excel:
одна строка — один студент, обязательны колонки «Ному насаби донишҷӯ»
(или «ФИО Студента») и «Гурӯҳ» (или «Группа»). Выберите нужные группы.
Колонки «Код факультета», «Дата», «ФИО Куратора», «ФИО Заместителя»
можно заполнить в Excel (одно значение для группы) или в таблице настроек
на странице. Даты указывайте в формате `10.10.2025`. В колонке «Отсутствует»
поставьте «да» для отсутствующего студента; он попадёт также в основной
список. Нажмите «Сгенерировать все документы», затем «Скачать все документы
ZIP». В архиве будет отдельный Word для каждой группы. Лимиты 40 студентов
и 10 отсутствующих проверяются для каждой группы; размер ZIP — до 64 МБ.

Оформление берётся из присланного DOCX: размеры страниц, таблицы, шрифты,
выравнивание и жирность окружающего текста сохраняются. ФИО заполняются
шрифтом 10 пт. Исправлена сетка колонок первой таблицы; номера 1–20
оформлены тем же шрифтом и жирностью, что и 21–40. Основные строки обеих
таблиц имеют минимальную высоту 28 пт, одинаковую для пустых и заполненных
ячеек. Остальные части пакета Word копируются без изменений.
При проверочном рендере документ занимает две страницы.
Фотография отличается от DOCX и служит примером заполнения. Длинные имена
могут увеличить высоту строк и число страниц, поэтому проверяйте документ
в Word перед печатью. Надпись должности в самом бланке остаётся исходной:
«Муовини декан оид ба тарбия».
